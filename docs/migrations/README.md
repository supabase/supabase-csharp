# Migration guides

One guide per major version, listing its breaking changes and what you need to do
about them. For the full, generated list of every change (features and fixes
included), see [`CHANGELOG.md`](../../CHANGELOG.md).

All packages are versioned in lockstep, so a major bump applies to every
`Supabase.*` package at once.

| Version | Guide |
| --- | --- |
| 8.0.0 | [Migrating to 8.0.0](./v8.0.0.md) |
| 9.0.0 (unreleased) | [Migrating to 9.0.0](./v9.0.0.md) |
